# Workflow: Failure Diagnosis

## 输入

- 失败现象。
- 传感器日志。
- 轨迹或地图结果。
- 运行配置。
- 对应 baseline 表现。

## 步骤

1. 描述可观察现象，不先下结论。
2. 在 `06_failure_modes` 中匹配候选失败模式。
3. 检查传感器链路：标定、同步、噪声、丢帧。
4. 检查状态估计链路：初始化、跟踪、优化、回环、重定位。
5. 设计最小诊断实验，区分算法问题和数据链路问题。

## 输出

- 候选原因列表。
- 最可能原因。
- 需要补充的证据。
- 诊断实验。
- 是否形成新的 failure mode 节点。
