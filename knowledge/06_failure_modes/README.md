# 06 Failure Modes

这里保存失败模式库。它是机器人视觉专家最重要的差异化资产之一。

## 失败模式

- 弱纹理。
- 重复结构。
- 动态遮挡。
- 运动模糊。
- 光照突变。
- 反光 / 透明物体。
- 地图过期。
- 初始位姿偏差。
- IMU bias。
- 时间同步误差。
- 标定漂移。
- Tracking lost。
- Relocalization failure。

## 每个失败模式应记录

- 现象。
- 触发条件。
- 可能原因。
- 受影响的方法族。
- 相关 baseline 表现。
- 诊断实验。
- 可复现数据。
- 对应论文或案例。
