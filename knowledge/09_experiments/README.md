# 09 Experiments

这里保存实验记录。实验不是调参流水账，而是研究假设的证据链。

## 实验类型

- Baseline reproduction。
- Ablation。
- Sensitivity analysis。
- Stress test。
- Minimum falsification experiment。
- Real robot closed-loop test。
- Long-run test。

## 每个实验应记录

- 研究假设。
- 数据集或场景。
- Baseline。
- 方法设置。
- 指标。
- 预期结果。
- 实际结果。
- 失败样例。
- 下一步假设更新。
