# 02 Sensors Calibration

这里保存传感器、标定、时间同步和噪声建模知识。

## 知识范围

- Camera。
- IMU。
- LiDAR。
- Wheel odometry。
- GPS / RTK。
- Depth camera。
- 外参标定。
- 时间同步。
- Rolling shutter。
- Sensor noise model。

## 专家需要回答的问题

- 算法依赖哪些传感器？
- 这些传感器的噪声和退化模式是什么？
- 标定或同步错误会如何表现？
- 一个 failure 是算法问题，还是传感器链路问题？
