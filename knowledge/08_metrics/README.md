# 08 Metrics

这里保存指标和评测协议。

## 离线指标

- ATE。
- RPE。
- Translation error。
- Rotation / yaw error。
- Tracking failure rate。
- Relocalization time。
- Loop closure precision / recall。
- Latency。
- CPU / GPU / memory。
- Uncertainty calibration。

## 闭环指标

- 导航成功率。
- 碰撞率。
- 到达时间。
- 轨迹效率。
- 长时间运行漂移。
- 失定位后恢复能力。

## 记录原则

每个指标都要说明：

- 衡量什么。
- 不衡量什么。
- 适合哪些任务。
- 容易被什么设置误导。
- 和真实机器人闭环之间有什么差距。
