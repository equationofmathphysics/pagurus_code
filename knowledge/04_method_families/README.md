# 04 Method Families

这里保存机器人视觉定位与建图的方法族。

## 方法族

- Feature-based VO / SLAM。
- Direct VO / SLAM。
- Visual-Inertial Odometry。
- RGB-D SLAM。
- LiDAR-inertial / visual-LiDAR fusion。
- Map-based Localization。
- Relocalization / Place Recognition。
- Semantic SLAM。
- Object-level SLAM。
- Neural / Learning-based SLAM。

## 每个方法族应记录

- 核心问题。
- 核心机制。
- 代表方法。
- 强 baseline。
- 关键假设。
- 典型失败模式。
- 常用数据集和指标。
- 当前研究空白。
