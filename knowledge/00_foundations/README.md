# 00 Foundations

这里保存机器人视觉专家需要反复调用的数学和研究地基。

## 知识范围

- 线性代数：坐标变换、特征值、矩阵分解、最小二乘。
- 概率与统计：噪声模型、贝叶斯估计、协方差、不确定性。
- 优化：非线性最小二乘、鲁棒核、梯度、Jacobian、Hessian。
- 李群李代数：SO(3)、SE(3)、扰动模型、pose update。
- 信息论：熵、信息增益、观测约束强度。

## 记录方式

每个主题不需要写成教材，只记录三件事：

- 它在机器人视觉里解决什么问题。
- 哪些算法会用到它。
- 常见误用或失败来源是什么。
