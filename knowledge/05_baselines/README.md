# 05 Baselines

这里保存强 baseline。一个新 idea 进入实现前，必须先经过 baseline gate。

## Baseline 卡片应记录

- 方法名称。
- 所属方法族。
- 传感器输入。
- 地图形式。
- 核心机制。
- 适用场景。
- 典型失败模式。
- 公开代码。
- 运行成本。
- 常用数据集结果。
- 我们是否已经复现。

## 第一批 baseline
